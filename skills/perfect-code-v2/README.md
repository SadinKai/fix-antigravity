# Perfect Code V2

A portable Antigravity Agent Skill for proportionate, evidence-directed software engineering and repository audits.

## Package contents

- `SKILL.md` — lean runtime entrypoint and evidence-directed coverage loop
- `references/coverage-loop.md` — substantial-task coverage, hypothesis, context, and strategy-switching protocol
- `references/review-matrix.md` — risk-weighted audit lenses and surface selection
- `references/verification-strategies.md` — claim-to-oracle selection and oracle-strength guidance
- `references/failure-modes.md` — adversarial failure classes, used selectively
- `references/optimization-protocol.md` — material design/rewrite comparison
- `references/research-dependencies-tools.md` — current external facts, dependencies, and command safety
- `references/native-antigravity-coexistence.md` — contracts with native Antigravity and the other core skill responsibilities
- `evals/evals.json` — behavioral evaluation scenarios
- `evals/trigger_evals.json` — positive and negative routing cases
- `evals/BENCHMARK.md` — matched baseline, ablation, and interaction evaluation guidance
- `agents/openai.yaml` — optional UI metadata

V2 intentionally keeps the always-loaded core smaller than V1 and routes conditional depth to references. The package does not include a planner, critic, memory system, browser layer, tool strategist, or replacement for Antigravity `/boost`, Teamwork, subagents, hooks, permissions, or deterministic validators.

The evaluation files make the intended behavior measurable. They do not demonstrate that V2 is empirically superior until controlled runs are performed.
